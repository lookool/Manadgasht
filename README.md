# مانادگشت

سایت آژانس مسافرتی «مانادگشت» — فروش تور، هتل و پکیج ترکیبی تور+هتل،
با زیرساخت آماده برای پنل ادمین و سیستم تورلیدر/کمیسیون در فازهای بعدی.

## این فاز چی داره؟

این نسخه‌ی اول، **بخش عمومی سایت** است: صفحه‌ی اصلی با اسلایدر، لیست و
جزئیات تور/هتل، بلاگ، درباره ما و تماس با ما — همه با دیتابیس واقعی
(PostgreSQL) پشتش. مدل‌های دیتابیس برای کاربر، ادمین، تورلیدر، کمیسیون
و سفارش هم از همین الان ساخته شده تا فاز بعد (پنل‌ها + احراز هویت +
منطق کمیسیون) روی همین پایه ساخته بشه، بدون نیاز به تغییر ساختار.

## ساختار پوشه‌ها

```
manadgasht/
  cmd/server/main.go        نقطه‌ی شروع برنامه، وایرینگ روترها
  internal/config/          خواندن تنظیمات از .env
  internal/database/        اتصال به پستگرس + مایگریشن خودکار جدول‌ها
  internal/models/          مدل‌های دیتابیس (User, Admin, Agent, Package, ...)
  internal/handlers/        هندلرهای HTTP هر صفحه
  web/templates/            فایل‌های HTML (Go html/template)
  web/static/               CSS و عکس‌ها
```

## راه‌اندازی

۱. مطمئن شو Go و PostgreSQL نصب هستن (طبق راهنمای مراحل قبل از شروع).

۲. یک دیتابیس با نام `manadgasht` توی PostgreSQL بساز.

۳. فایل `.env.example` رو کپی کن و اسمش رو بذار `.env`، بعد
   `DB_PASSWORD` رو با پسورد واقعی کاربر postgres پر کن.

۴. توی ترمینال، داخل پوشه‌ی پروژه:

```bash
go mod tidy
go run cmd/server/main.go
```

۵. مرورگرت رو باز کن روی `http://localhost:8080`.

با اجرای اول برنامه، جدول‌های دیتابیس خودکار ساخته می‌شن. چون هنوز پنل
ادمین نداریم، دیتابیس خالیه؛ صفحات لیست تور/بلاگ فعلاً «هنوز چیزی ثبت
نشده» نشون می‌دن — طبیعیه، فاز بعد که پنل ادمین رو اضافه کنیم پر میشه.

## نکته درباره‌ی go.sum

چون این محیط به اینترنت وصل نیست، فایل `go.sum` ساخته نشده. اولین باری
که `go mod tidy` رو روی سیستم خودت بزنی، Go خودش کتابخونه‌ها رو دانلود
و این فایل رو می‌سازه؛ کاملاً عادیه.

## فاز بعدی (قدم بعدی که با هم می‌سازیم)

- پنل ادمین: مدیریت تور/هتل، بلاگ، تورلیدرها و تنظیم درصد کمیسیون
- پنل تورلیدر: مشاهده‌ی کد معرف، آمار فروش و کمیسیون کسب‌شده
- احراز هویت کاربر/ادمین/تورلیدر (ورود و ثبت‌نام)
- منطق ثبت سفارش با اعمال کد معرف و محاسبه‌ی کمیسیون
- رزرو آنلاین (جایگزین تماس/واتساپ) در آینده
