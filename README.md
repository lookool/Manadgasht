# مانادگشت

سایت دفتر خدمات مسافرتی «مانادگشت» — فروش تور، هتل و پکیج ترکیبی
تور+هتل. ظاهر بر اساس رنگ/فونت/محتوای واقعی manadgasht.com بازسازی
شده، با چند المان بصری الهام‌گرفته از arandtour.com (کارت‌های
دسته‌بندی و بنر پیشنهاد ویژه) برای جذابیت بیشتر.

## معماری کد

پروژه به‌صورت لایه‌ای نوشته شده تا هم تست‌پذیر باشه، هم افزودن فاز ۲
(پنل‌ها + کمیسیون) بدون به‌هم‌ریختن کد فعلی ممکن باشه:

```
cmd/server/main.go     فقط "وایرینگ": همه‌چیز رو به هم وصل می‌کنه و سرور رو بالا میاره
internal/config/       خواندن تنظیمات از .env
internal/database/     اتصال به Postgres + مایگریشن خودکار جدول‌ها
internal/models/       مدل‌های دیتابیس (Package، BlogPost، User، Admin، Agent، ...)
internal/repository/   تنها لایه‌ای که مستقیم با دیتابیس/GORM صحبت می‌کنه
internal/service/      منطق تجاری؛ هندلرها فقط با این لایه کار می‌کنن
internal/handlers/     کنترلرهای HTTP (ورودی/خروجی، رندر تمپلیت)
internal/router/       تعریف مسیرها (جدا از main.go)
web/templates/         فایل‌های HTML (Go html/template)
web/static/            CSS و عکس‌ها
```

قانون ساده: **هندلر هیچ‌وقت مستقیم به دیتابیس دسترسی نداره**، همیشه از
طریق service. و service هم مستقیم gorm صدا نمی‌زنه، از طریق repository.

## این فاز چی داره؟

بخش عمومی سایت: صفحه‌ی اصلی با هیرو+جست‌وجو، دسته‌بندی سریع (تورهای
داخلی/خارجی/هتل/پکیج ترکیبی)، لیست و جزئیات تور/هتل، بلاگ، درباره ما،
تماس با ما، و ویجت شناور تماس/واتساپ. مدل‌های دیتابیس برای پنل ادمین،
تورلیدر و کمیسیون هم از همین الان ساخته شدن (User، Admin، Agent،
CommissionSetting، Order) تا فاز بعد روی همین پایه پیش بره.

**چیزی که هنوز نیست:** پنل ادمین، پنل تورلیدر، لاگین/ثبت‌نام، و منطق
واقعی ثبت سفارش با کد معرف — اینا فاز ۲ هستن.

## راه‌اندازی

۱. مطمئن شو Go و PostgreSQL نصب هستن.
۲. یک دیتابیس با نام `manadgasht` توی PostgreSQL بساز.
۳. فایل `.env.example` رو کپی کن، اسمش رو بذار `.env`، و `DB_PASSWORD`
   رو با پسورد واقعی پر کن.
۴. توی ترمینال، داخل پوشه‌ی پروژه:

```bash
go mod tidy
go run cmd/server/main.go
```

۵. مرورگرت رو باز کن روی `http://localhost:8080`.

با اجرای اول، جدول‌های دیتابیس خودکار ساخته می‌شن. چون هنوز پنل ادمین
نداریم، دیتابیس خالیه؛ صفحات لیست تور/بلاگ فعلاً چیزی نشون نمی‌دن —
طبیعیه، فاز بعد که پنل ادمین اومد پر میشه.

## نکته درباره‌ی go.sum

چون این پروژه بدون اتصال به اینترنت آماده شده، فایل `go.sum` ساخته
نشده. اولین باری که `go mod tidy` رو روی سیستم خودت بزنی، Go خودش
کتابخونه‌ها رو دانلود و این فایل رو می‌سازه؛ کاملاً عادیه.

## ورژن‌بندی با Git

این پروژه از همین الان با `git` مقداردهی اولیه شده و شامل چند کامیت
مرحله‌به‌مرحله‌ست (پیکربندی → مدل‌ها → repository → service → هندلرها
→ رابط کاربری) که با:

```bash
git log --oneline
```

می‌تونی ببینیشون. برای بالا بردن روی گیت‌هاب:

```bash
git remote add origin <آدرس ریپوی خودت روی گیت‌هاب>
git branch -M main
git push -u origin main
```

از این به بعد هم برای هر تغییر بزرگ (مثلاً فاز ۲: پنل ادمین)، بهتره
یک کامیت جدا با پیام مشخص بزنی؛ می‌تونیم این کار رو هم مرحله‌به‌مرحله
با هم انجام بدیم.

## فاز بعدی

- پنل ادمین: مدیریت تور/هتل، بلاگ، تورلیدرها و تنظیم درصد کمیسیون
- پنل تورلیدر: کد معرف، آمار فروش و کمیسیون کسب‌شده
- احراز هویت کاربر/ادمین/تورلیدر
- منطق ثبت سفارش با اعمال کد معرف و محاسبه‌ی کمیسیون
- رزرو آنلاین (جایگزین تماس/واتساپ) در آینده
